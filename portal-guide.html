02 ความสามารถของแอป · แต่ละหน้า

🤝
เจรจา
งานสัญญา
  • ติดตามสัญญา 6 ขั้น: เจรจา → เสนอ KT → รอเซ็น → รอส่งตรวจ → รอกฎหมายตรวจ → เซ็นแล้ว
  • เตือนงาน ค้างเกิน 90 วัน (แดง) เรียงค้างนานสุดก่อน
  • ปุ่มตอบผล “เซ็นสัญญาแล้ว” → ปิดงานเจรจา
📐
รังวัด
งานทีมเจรจา
  • 4 ขั้น: รอรังวัด → นัดวันรังวัด → รังวัด → ส่งผลให้ก่อสร้าง
  • SLA รอรังวัด 10 วันทำการ จากวันอนุมัติรถตู้
  • ปุ่มตอบผลไล่สถานะได้ทีละขั้น
🏛️
รัฐกิจ
อ.1 + ทะเบียน
  • อ.1 5 ขั้น (ติดตามเอกสาร → ยื่น → ติดตาม → ได้ใบ) · SLA ตจว. 45 / กทม. 60 วัน
  • ทะเบียน เช็คลิสต์ ~15 ใบ พร้อมเตือน D-day จากวันเปิด
  • รองรับ “อนุโลม” (ก่อสร้างก่อนได้ใบ)
🏪
รายสาขา
งานค้างต่อสาขา
  • รวมงานค้าง ทุกท่อน ของแต่ละสาขาไว้ในแถวเดียว
  • กรองด้วย rail (เจรจา/รังวัด/อ.1/ทะเบียน) · KPI · จังหวัด · เฉพาะเกิน SLA
  • คลิกสาขา → เห็นทุกงานที่ต้องทำ + ปุ่มเปิดจัดการข้ามท่อน

03 ตรรกะ & กติกาที่แอปใช้

ข้อมูลเป็น Live — คำนวณในเบราว์เซอร์

ไม่ฝังข้อมูล ดึงสดจากชีตทุกครั้งที่เปิด แล้วคำนวณ step/SLA/สถานะเอง · รีเฟรชอัตโนมัติทุก 5 นาที

Site Code = คีย์เชื่อมทุกทีม

ข้อมูลจากชีตเจรจา · SLA · ทะเบียน · ก่อสร้าง ถูก join เข้าด้วยกันด้วย Site Code — ถ้ารหัสไม่ตรงกัน ข้อมูลจะไม่มารวม

“ร้านเปิดแล้ว = ไม่มีงานค้าง”

สาขาที่เปิดแล้วถูกตัดออกจากทุกท่อน (ยกเว้นทะเบียน ที่ทำต่อหลังเปิดได้) · ตรวจ “เปิดแล้ว” จากชีตก่อสร้าง (Active/Hide + วันเปิด ≤ วันนี้) เสริมด้วยสถานะในชีต SLA (9.Opened)

การแบ่งขั้น (step) ของงานเจรจา

Main Status 3 หรือ 4 = เซ็นแล้ว (จบ) · ที่เหลือแกะจากวันหมุด (ส่งกฎหมาย → กฎหมายกลับ → ส่งเจ้าของเซ็น) · ถ้าชีตมีคอลัมน์ “สถานะสัญญา” จะใช้ระบุขั้นตรงๆ (แม่นสุด)

เกณฑ์ SLA แต่ละท่อน

เกินกำหนด = ขึ้นแดง เรียงด่วนสุดก่อน

เจรจา · 90 วันรังวัด · 10 วันทำการอ.1 · ตจว. 45 / กทม. 60 วันทะเบียน · D-day จากวันเปิด

งานรังวัด — นับทุกสาขาที่ยังไม่รังวัด

สาขาที่ อนุมัติทำเลแล้ว + ยังไม่มีวันรังวัด + ยังไม่เปิด = เข้าคิวรอรังวัด (opened เท่านั้นที่ตัดออก)

ทะเบียน — ใช้เกณฑ์ “จดครบ = จบ” ของตัวเอง

งานทะเบียนทำช่วงใกล้/หลังเปิดร้าน จึงไม่ตัดสาขาที่เปิดแล้ว — สาขาเปิดแล้วแต่เอกสารยังไม่ครบยังแสดงอยู่ จนจดครบทุกใบ

“ตอบผล” ในแอป = Overlay (ไม่แก้ชีตต้นทาง)

เมื่อทีมกดตอบผล ระบบเก็บลงชีตกลาง แล้วเอามาทับข้อมูลฐานตอนแสดงผล · ชีตต้นทางของแต่ละทีมยังเป็นเจ้าของเหมือนเดิม

กราฟ Cohort — อนุมัติรถตู้ → ปิดดีล

จัดกลุ่มสาขาตามเดือนที่อนุมัติรถตู้ แล้วนับว่ากี่รายเซ็นสัญญาจบแล้ว (เขียว) เทียบกับยังไม่เซ็น (เหลือง) + %ปิดดีล

สิทธิ์การเข้าถึง (Role)

member เห็นเฉพาะงานตัวเอง · governance แก้ได้เฉพาะ อ.1 + ทะเบียน · admin / หัวหน้า เห็นและแก้ได้ทุกอย่าง
