สิ่งที่ควรรู้

1. ข้อมูลเป็น live — เปิดแอปทีไรดึงสดทุกครั้ง ไม่มีการฝังข้อมูล เปลี่ยนในชีตแล้วรีเฟรชเห็นเลย (แอป auto-refresh ทุก 5 นาที)

2. คีย์เชื่อมทุกชีตคือ Site Code — ถ้ารหัสสาขาในชีตต่างกัน ข้อมูลจะไม่ join กัน

3. “ตอบผล” ในแอปไม่แก้ชีตต้นทาง — จะเก็บใน updates แล้วเอามาทับตอนแสดงผล (overlay) ชีตต้นทางยังเป็นของทีมเจ้าของเหมือนเดิม

4. “ร้านเปิดแล้ว = ไม่มีงานค้าง” เป็นกฎหลัก — สาขาที่เปิดแล้วถูกตัดออกจากทุกท่อน (ยกเว้นทะเบียนที่ยังทำต่อหลังเปิดได้)
