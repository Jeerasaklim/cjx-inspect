เข้าสู่ระบบ

กำลังตรวจ session…

1) สำรองทุกตารางเป็นไฟล์ (ทำก่อน — กันหายเพิ่ม)

ดึงทุกแถวจาก stores / checkpoints / inspections / check_events / signoffs / media / profiles / contractors → ดาวน์โหลดเป็น JSON เดียว

2) ตรวจไฟล์รูป/วิดีโอใน Storage ที่รอด

SQL ลบแค่แถวในตาราง media — ไฟล์จริงใน Storage อาจยังอยู่ครบ กดตรวจ

3) ดาวน์โหลดรูป/วิดีโอทั้งหมดเก็บลงเครื่อง (ZIP)

โหลดไฟล์ที่รอดทั้งหมดจาก Storage เป็น .zip เก็บไว้ (ต้องกดข้อ 2 ก่อน)

⭐ 4) กู้รูปคืนเข้าแอป — สร้างแถว media ที่หายจากไฟล์ที่รอด

ไฟล์รูปใน Storage ยังอยู่ แต่แถวในตาราง media หาย รูปเลยไม่โผล่ในแอป · ปุ่มนี้อ่านชื่อไฟล์ (มี checkpoint id อยู่ในชื่อ) แล้วสร้างแถว media คืน — INSERT อย่างเดียว ข้ามอันที่มีอยู่แล้ว ไม่ลบ ไม่ทับอะไร · กดข้อ 2 (สแกน) ก่อน
